# 原始 P0-DDPNM：二维与三维严格误差比较

两组误差现已采用同一计算口径：

- DDPNM 与整体 Taylor--Hood FEM 使用同一张网格；
- 局部 DDPNM 场在子区域两侧保持独立；
- 误差在每个子区域逐单元积分，不进行界面平均；
- 速度使用严格相对 L2 和 broken-H1 半范数；
- 压力同时报告原始 L2 与去除平均漂移后的 L2；
- 使用六阶求积。

| 指标 | 2D 随机圆孔 | 3D 规则球阵列 | 3D/2D |
|---|---:|---:|---:|
| 速度相对 L2 | 5.17% | 21.86% | 4.23 |
| 速度 broken-H1 | 9.55% | 45.31% | 4.75 |
| 压力原始相对 L2 | 0.35% | 2.88% | 8.31 |
| 压力去均值相对 L2 | 0.86% | 5.27% | 6.11 |
| 出口流量误差 | 0.92% | 18.72% | 20.32 |

二维旧记录中的节点采样误差为：速度 5.829%、压力 0.422%。严格体积分得到的速度 L2 为 5.169%，与旧记录一致到同一量级；因此此前“二维约 5.8%”并非计算错误，只是误差范数不同。

这组结果可以确认：在当前两个具体算例中，三维原始 DDPNM 明显比二维差，尤其是流量和速度梯度。但它仍不能单独证明差异完全由空间维数造成，因为二维使用 17 个随机圆孔、27 个子区域和 35 条界面，三维使用 27 个规则球、64 个子区域和 144 条界面；孔隙率、配位数和孔喉面积分布均未匹配。

如果要形成严格的“维度效应”结论，下一步应构造孔隙率、归一化孔喉宽度和网络配位数匹配的二维/三维基准组。
