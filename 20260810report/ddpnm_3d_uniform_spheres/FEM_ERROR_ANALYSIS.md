# 3D DDPNM 与传统 FEM：同网格误差分析

## 比较设置

两种方法严格使用同一张共形四面体网格：34,341 个四面体、8,654 个顶点，
网格 SHA-256 为
`D6BF6808572946932C93909CA21BAC4DDFE6CEB6F1FB3556BB9C011841AB567A`。
逐点坐标、四面体连接和最大球子域标签也已逐数组确认完全相同。

- 传统 FEM：全局连续 Taylor–Hood `[P2]^3-P1`，181,427 个混合自由度；
- 原始 DDPNM：64 个局部 Taylor–Hood 问题，每条内部界面只有一个常数法向
  牵引自由度；
- 黏度、球壁与外壁无滑移条件、入口/出口压力牵引完全一致；
- 两种方法的压力稳定化系数都为零。

整体 FEM 使用块预条件 GMRES。正式计算经过 188 次迭代达到
`1.056e-10` 的真实代数相对残差；入口—出口相对质量不平衡为
`2.255e-10`，能量平衡相对残差为 `8.303e-11`。

## 误差定义

全局 FEM 解被按完全一致的 P2/P1 Lagrange 节点严格限制到每个 DDPNM
子网格。随后采用六阶积分逐四面体计算，不使用顶点平均或单元中心近似：

```text
e_u,L2 = [Σ_i ∫_{Ω_i}|u_DD-u_FE|² dx]^(1/2) / ||u_FE||_L2,
e_u,H1 = [Σ_i ∫_{Ω_i}|∇u_DD-∇u_FE|² dx]^(1/2) / |u_FE|_H1,
e_p,L2 = [Σ_i ∫_{Ω_i}|p_DD-p_FE|² dx]^(1/2) / ||p_FE||_L2,
e_Q    = |Q_DD-Q_FE|/|Q_FE|.
```

入口/出口自然压力牵引固定了绝对压力基准，因此主压力误差直接比较原始压力，
没有任意减去均值。报告中另列出消除常数偏差后的辅助压力误差。

## 正式结果

| 指标 | 数值 |
|---|---:|
| 速度相对 L2 误差 | 21.8635% |
| 速度 broken-H1 半范数相对误差 | 45.3107% |
| 压力原始相对 L2 误差 | 2.8776% |
| 压力消常数辅助相对 L2 误差 | 5.2652% |
| DDPNM−FEM 压力体积均值差 | -1.548e-4 |
| FEM 出口流量 | 1.94985e-3 |
| DDPNM 出口流量 | 2.31484e-3 |
| 出口流量相对误差 | 18.7187% |

## 结果解释

原始 DDPNM 对压力的平均传递描述较好，因此压力 L2 误差只有约 2.9%。
但每个孔喉仅保留一个常数法向牵引，不能表达切向牵引、截面内线性变化及完整
速度迹，所以速度 L2 误差约 21.9%，梯度误差更高。误差图显示速度误差主要
集中在球间窄孔喉和鞍点截面附近；压力误差则沿人工子区域界面呈现明显的分片
跳跃。DDPNM 的出口流量比 FEM 高约 18.7%，说明这个最低阶界面模型在当前
算例中给出了偏大的整体导通能力。

误差切片选在 `z=0.48`，而不是 `z=0.5`。后者正好是 DDPNM 的人工界面，
存在两个独立迹；对两侧求平均会人为隐藏界面误差。图中每个四面体独立切片并
保留所属子区域的单侧值，没有跨 DDPNM 界面做平滑或平均。

这些结果说明下一步引入 DDPNMT 的切向模式和 HODDPNM 的线性/高阶界面模式
是必要的。仅继续细化体网格不能消除由界面空间过低造成的模型降阶误差。
