# 论文路线图：DDPNM 二维→三维升维（2026-08-05）

> 目标：把现有数值结果（随机球 + 均匀球 + 2D 基准）组织成一篇
> "升维机理 + 模态设计 + 半理论误差界"的数值方法论文。
> 当前定位：**CMAME 现实目标，JCP 冲刺目标（界严格 + 控制算法时），
> C&F / IJNMF / AWR 稳妥落点**。
> 本文档的每个待办都有：内容、前置、工作量、验收标准。

---

## 0. 论文主线（四幕叙事）

1. **升维的几何断裂**：2D 界面是连心线上的 1D 线段（端点由两个圆支撑，
   `ddpnm_2d_random_porous/ddpnm2d/geometry.py` `analytic_throat_cuts`）；
   3D 里 1D 线段不能分割体积，子区域构造必须重新发明——Voronoi 胞/
   垂直平分面 vs 净距盆/鞍面，且半径不均匀（0.079–0.133）时两者不重合
   （鞍点位移 0.0073/2.8%、Hausdorff 中位 0.0858）。
2. **升维的代数断裂**：把 2D 的"每界面一个常数法向系数"硬搬到 3D =
   Classic-DDPNM，L2 误差 21%（均匀球）~65%（随机球）。
3. **双假说判别（核心章节）**：假说 A（压缩比）：3D 每界面 1 代表点代替
   ~100 真实节点；假说 B（模态形状）：单模态表达力不足。四线判别：
   - 每面 15 采样点（Uniform-DDPNMT）vs 9 模态（Affine）**打平**
     （5.47% vs 5.63%，`affine_ddpnm_3d/RESULTS.md`）→ A 出局；
   - 模态 1→9：21.1%→5.63%（均匀）、65%→6.51%（随机）→ B 成立；
   - 网格加密三档无改善（10.9/11.3/14.3%）→ 离散误差不是瓶颈；
   - 弯折度与误差相关（246/369 界面 >30° 竖面，W 差于 V）→
     主因 = **模态形状与界面几何的匹配**。
4. **解法与边界**：Affine-DDPNM（每面 9 模态 {1,s,t}×{n,t1,t2}）在平面
   界面上 5.6–6.5%、流量误差 <3%、在线 136×、守恒舍入级；弯折界面
   （watershed）退化（14%）不是失败，是主因的可控验证。

## 1. 期刊定位与三个验收条件

| 层 | 期刊 | 条件 |
|---|---|---|
| 冲刺 | JCP | 误差界严格（有证明）+ 控制算法带收敛性论证 |
| 现实 | CMAME | 半理论界（严格或启发式）+ 完整数值 + 控制算法 + 2D/3D 匹配对比 |
| 稳妥 | C&F / IJNMF / AWR | 理论只有启发式或控制算法缺失；AWR 对口多孔介质 |

**决定档次的三个条件**：
1. **界严格性**：弯折（阶梯）界面误差界是证明过的还是启发式+数值吻合；
2. **"控制 H1 误差"有算法**：残差驱动指示器 → 界面增选模态 → H1 单调
   下降且被界控制（带论证）。只有解释没有算法会被审稿人挑战；
3. **2D/3D 匹配对比严格**：同孔隙率/配位数匹配（STRICT 基础设施现成）。

## 2. 待办清单（按执行顺序）

### A. 核实 2D 对照数据（先行，约半小时）
- **内容**：读 `ddpnm_2d_random_porous/RESULTS.md` 与 STRICT_2D_3D_COMPARISON.md，
  确认：2D Classic-DDPNM 的 L2 误差水平；2D 的 interface_order 0/1（P0/P1）
  数字；2D 模态数对误差的改善曲线。
- **为什么**：主线 1 的"常数模态表达缺口随界面维度翻倍（1D→2D）"叙事
  需要 2D Classic 明显好于 3D Classic（如 2D ~10% vs 3D 21%/65%）；若 2D
  也是 20–30%，叙事要调整为"缺口结构不同"而非"缺口翻倍"。
- **验收**：一张 2D/3D Classic 对照表 + 叙事表述定稿。

### B. 表述修正（写作，1 天内）
- **内容**：
  1. "硬搬 2D 产生灾难性后果"→ 改为"维度不匹配（1D 线段不能分割体积）
     + 常数模态缺口随界面维度变化"（落点取决于 A 的数据）；
  2. "确定第二个原因是主要原因"→ 改为"**精度主因 = 模态形状-几何匹配；
     成本瓶颈 = 界面未知量阶数 O(h⁻²)**"（成本侧数据已有：离线库近似
     线性于界面数：12.2 s/114、15.0 s/257、15.0 s/326）；
  3. broken-H1 写进"误差结构分析"（见 F）。
- **验收**：主线 0 的四幕定稿，无稻草人、无原因-后果错位。

### C. 种子扫描（1–2 天，可并行挂后台）
- **内容**：3+ 个随机排布。参数化 `_gen_spheres.py`（或加种子参数），
  保证：9 内部球 + 18 裁剪壁球、无重叠、孔隙率/配位数相近。
  每种子重跑 V×{Classic,Affine}、W×{Classic,Affine}（0.13 族即可）。
- **前置/关键坑**：**每种子必须重做 watershed 阈值扫描**——盆数对网格和
  阈值敏感（0.13 族 82 盆、0.10 族 50 盆、0.04 族 10 盆），确认 0.02/0.05
  在新排布下仍落在盆数稳定区间，否则四组合误差不可比。
- **验收**：3+ 种子 × 4 组合的 report json；种子间 6.5%/14% 量级的散布
  统计（均值 ± 标准差）。

### D. 误差分解实验（数值，1–2 天）
- **内容**：把误差分离成三块：
  - 离散误差：精确 FE-trace Schur 解为基准（Voronoi 舍入级、watershed
    3.2e-7——`run_watershed_exact_schur.py` 现成），DDPNM vs Schur =
    纯模型误差；
  - 画法误差：把 watershed 界面替换为光滑化/理想界面（或对比
    V vs W 的模型误差），分离弯折的影响；
  - 模态误差：Classic vs Affine 差分。
- **验收**：一张"误差分解表"（三项 × 四组合），主因叙事从排除法升级为
  可验证的分解。

### E. 谱分析半理论（1–2 个月，最大工作量，范围必须锁定）
- **内容（范围锁定版）**：
  1. 平面界面上仿射模态完备性（平凡可证，几页纸）；
  2. 模态空间的谱刻画 → 模态投影误差 ||u − P_modal u|| 的估计 → L2/H1
     误差地板的理论预测（与实测 6.5%/14% 对比）；
  3. 弯折（阶梯）界面的法向跳变如何进入误差界——**若严格界做不出，
     预设退路**：启发式界 + 数值吻合（仍是 CMAME 级）；
  4. broken-H1 与 L2 是同一谱的两个范数（一并处理，不要单独做）。
- **不做**：完整先验误差分析（角点奇异性常数的引理证明会失控）。
- **验收**：理论预测地板 vs 实测地板的对照表（L2 和 H1 各一组）+ 对
  四线判别实验的逐一解释（理论解释四个观察，而非独立估计）。

### F. broken-H1 处理（写作 + 可选数值，2–3 天 + 视情况）
- **必做（解释它）**：误差结构分析一节——broken-H1 高是界面薄层的导数
  误差集中（误差云图证据：高亮贴界面迹线），与主因同步（V 17.56% vs
  W 34.42%，加密无改善），工程量（流量 2.7%）不受影响。
- **可选（压它/验证地板可移动）**：面内 P2 富集一档
  （{1,s,t,s²,st,t²}×{n,t1,t2} = 18 模态/界面，V 上跑），预计
  broken-H1 17.6% → ~10% 级——作为谱理论"地板可移动"的数值验证。
  参考 2D `ddpnm2d/basis_2d.py` 的 PolynomialNormalBasis。
- **验收**：broken-H1 有解释、有空间证据、有（或明确没有）P2 对照。

### G. 2D/3D 匹配对比（1–2 周，STRICT 基础设施现成）
- **内容**：同孔隙率/配位数匹配的 2D vs 3D 基准（`ddpnm_2d_random_porous`
  的 strict 对比框架）：Classic/Affine 的 L2/H1/通量/未知量/加速比对照。
- **验收**：跨维度对照表 + 主线的"界面维度 1D→2D"定量支撑。

### H. 升阶实验（可选，与 F 合并考虑）
- **内容**：HODDPNM 式残差驱动界面富集——同时压 broken-H1（34% 靶子）
  和未知量阶数 O(h⁻²)→O(h⁻¹)（承接"成本瓶颈"叙事）。
- **验收**：富集后 broken-H1 单调下降 + 未知量/精度权衡曲线。
- **注意**：这是 C 和 E 之后的增强项，不是主线必需。

## 5. 风险与退路

- **界不严格**：退到启发式界 + 数值吻合 → 仍是 CMAME 级，放弃 JCP；
- **"控制"无算法**：只写"解释"，标题/摘要避开"控制"字样 → 落 C&F/IJNMF；
- **种子间散布大**（盆数/误差不稳定）：阈值重标 + 报告散布，不硬压；
- **时间不够**：E 只做完备性 + 数值地板对照（第 1 项 + 第 2 项最简版），
  其余以数值为主——保住 CMAME 的下限。
