# Affine-DDPNM 驱动两相 Buckley–Leverett 验证结果（2026-08-11）

随机 27 球 3D 介质（15249 胞 / 27 孔 / 114 界面），水驱油两相饱和度输运
（Corey 分流量，`Swr=Sor=0.2, nw=no=2, μw=1, μo=5`，初始 `Sw=0.2`，
注入 `Sw=0.8`），dt=0.1, t=30（300 步）。四个固定总速度场各驱动一次输运，
全部误差以 FEM 速度驱动结果为参考。

## 结论

1. **误差单调传递**：模态越丰富 → Stokes 速度越准 → 两相输运越准。
   三档速度误差（65.3% → 30.7% → 6.5%）在饱和度场（39.5% → 14.2% →
   7.5%）、含水率（2.27 → 0.96 → 0.15）、采收率（61.6% → 12.7% → 2.5%）
   上完全同序。Affine-9 是唯一把输运误差压到 10% 以下的档位。
2. **采收率系统性偏高**：三方法全为正偏差（+14.9pp → +2.8pp → +0.6pp），
   与单相 tracer 的"breakthrough 偏早"结论自洽——速度误差使水前端推进
   偏快，采收率虚高。Affine 偏差已降到亚百分点。
3. **质量守恒到机器精度**（~1e-13）：限幅器保证物理区间 [0.2, 0.8]，
   独立边界通量账本 `M^{n+1} − M^n + dt(Q_out − Q_in)` 成立。
4. **非线性放大**：两相（非线性双曲）的误差放大远强于单相线性 tracer
   （采收率 pp 量级 vs 浓度 1e-3 量级）——前端对速度场相位误差敏感。

## 一维标准解验证（`validate_1d_buckley_leverett.py`）

同一 P1 CG 有限元配方的 1D 镜像对照解析解（Welge 切线 + rarefaction +
冲击波）：前端位置误差 −5.7%、L1 3.8 单元糊化、质量误差 ~1e-8（Picard
截断）、守恒残差 ~5e-13、无越界。修复版有限元配方在 1D 上正确推进前端。

## 性能

优化后（SUPG 系数冻结于步初 + Picard 上限 6）：每步 ~1.8 s（原 ~9 s），
完整 benchmark（FEM + 三档 DDPNM × 300 步）~48 分钟。
