# 网格收敛验证报告(2026-08-12)

> 验证交接文档待办第 1 项:"Classic O(h) vs Affine O(h²) 的逼近阶主张需要
> 2–3 档网格的速度误差收敛率"。本报告为该主张的实测验证结果。
> 运行:`conda run -n fenicsx --no-capture-output python run_mesh_convergence.py`
> 重绘图:`python plot_mesh_convergence.py`(只读 `convergence_report.json`)。

## 0. 结论(一句话)

**误差不随网格细化收敛**:三档网格(粗 0.17 / 中 0.13 / 细 0.10)上
Classic / W1n / Affine 的速度与压力误差相对同网格 FEM 参考均为平台值
(速度 L2 ≈ 65% / 30.5% / 6.5%),经验收敛阶 |p| ≤ 0.2——交接文档中
"Classic O(h) vs Affine O(h²) 的逼近阶主张"**不被数据支持**。

**修正后的正确表述**:界面牵引模态空间由几何(Voronoi 面)决定、与网格
无关(三档网格模态数恒为 114/342/1026);网格细化只细化界面面片剖分与
孔内局部子问题,不增加牵引逼近自由度。因此 h→0 时误差趋于固定的降维
误差平台 E_space > 0,**精度的提升来自模态丰富度**(嵌套空间
P0 ⊂ {P0,P1}×n ⊂ {P0,P1}×{n,t1,t2} → 65% → 31% → 6.5%),而非网格细化。

## 1. 设置

同一随机 27 球几何(冻结 seed-20260804 球堆 + Voronoi 喉面),按基准
参数族整体缩放 6 个网格尺寸/带参数生成三档自相似网格(仅分辨率不同,
114 个界面在每档相同):

| 档 | bulk | h = ⟨V^{1/3}⟩ | 四面体 | 顶点 | 网格生成(s) |
|---|---:|---:|---:|---:|---:|
| 粗 | 0.17 | 0.04371 | 9845 | 2234 | 45.4 |
| 中 | 0.13 | 0.03756 | 15249 | 3483 | 60.5 |
| 细 | 0.10 | 0.03163 | 25082 | 5714 | 21.5 |

每档:单片 Taylor-Hood P2–P1 FEM 参考 + 三方法 DDPNM(Classic-1 / W1n-3 /
Affine-9),误差用归档指标管线(`finite_element_error_analysis`,逐孔
P2–P1 精确积分 + 全局均值对齐压力)。中档与归档 benchmark **逐位一致**
(Classic 65.3203% / W1n 30.7488% / Affine 6.5058%,dofs 75954,15249 胞),
验证了本研究的可比性。

| 方法 | velL2 | velH1 | p(压力对齐) | 全程回归斜率(velL2) |

## 4. 机理与含义

1. **为什么平台化**:界面牵引模态空间是几何对象(Voronoi 面、每面
   1/3/9 个模态),三档网格模态数恒为 114/342/1026。h 细化仅改善
   (a) 界面面片的求积分辨率和 (b) 孔内局部 Stokes 子问题的 FEM 精度;
   当 (b) 收敛后,误差 = 精确降阶解 − 精确全局解 = 牵引空间逼近残差,
   由几何决定、非零。本网格尺寸已处于平台。
2. **正确的精度杠杆是模态丰富度**:Classic→W1n→Affine 单调
   65% → 30.5% → 6.5%,即嵌套模态空间的逼近性质(交接 §2 机制结论仍
   成立),而交接文档"Classic O(h) vs Affine O(h²)"的收敛阶表述不成立,
   应改为"固定模态数下误差平台化;丰富模态才能降误差"。
3. **对两相输运的含义**:Affine 采收率 +0.6 pp 偏差是牵引空间残差
   (≈6.5%)经输运放大的结果,不是网格离散伪影;压低它需要更多模态/
   面(或自适应模态分配),h 细化无效。
4. **h 细化的真实作用**:(i) 提高 FEM 参考与局部子问题的绝对精度;
   (ii) 两相输运数值扩散本身受网格影响(但那是输运求解器的问题,与
   本研究的 Stokes 降维误差无关);(iii) 为局部响应库提供更准的子问题。
