# 速度扰动 → 采收率敏感度:1D 解析对照(2026-08-12)

> 验证交接文档待办第 4 项:"1D BL 解析解上做速度扰动→前端/采收率敏感度
> 分析,与 3D 经验传递关系(0.6–14.9 pp)对照"。
> 运行:`conda run -n fenicsx --no-capture-output python run_1d_sensitivity.py`
> 重绘图:`python plot_1d_sensitivity.py`(只读 `sensitivity_report.json`)。

## 0. 结论(一句话)

3D 采收率偏差(Classic +14.9pp / W1n +2.8pp / Affine +0.6pp)精确分解为
**通量通道**与**泄漏通道**:

```
ΔR = 1.25·ΔPVI − leak
```

其中 1.25·ΔPVI 是 DDPNM 总通量误差经质量守恒律的**直接放大**(主导项,
占 ΔR 的 133–151%),leak 是快流线提前出水造成的次级修正(抵消 25–30%)。
1D 解析/数值验证:突破前 R = 1.25·PVI **精确到 1e-8**;零均值结构扰动
(入口不动)ΔR = 0 而场误差 ∝ ε;速度误差的相干分量 θ = η/ε(W1n/Affine
0.43–0.48,Classic 1.12)决定 ΔR/ε 斜率。

## 1. 方法与设置

- **1D 求解器**:P1 CG 镜像(与 3D 同款:隐式欧拉 + Picard + 残差 SUPG +
  迎风边界数值通量 + 物理区间守恒限幅器),本会话扩展为变速度 u(x);
  L=10、nx=400、dt=0.0025(纯冲击 CFL ~0.28)、参考 PVI 0.23(与 3D t=30 对齐)。
- **参数与 3D 逐项相同**:Corey Swr=Sor=0.2、nw=no=2、μw=1、μo=5、
  Swi=0.2、S_inj=0.8。Welge 解:v_s = 2.875、S* = 0.443(注意:非纯冲击
  弦速 1.667——前端是 rarefaction+shock 复合波,但质量律与剖面无关)。
- **扰动族**(rel L2 = ε,与 3D 速度误差同口径):
  - coherent(θ=1):u ≡ 1+ε,入口值 = ε;
  - structure(θ=0):27 孔零均值 ±1,δ(0)=0(入口通量不动),ε ∈ {0.065, 0.653};
  - mixed(θ=0.45):δ = θε + √(1−θ²)ε·噪声,入口值 = θε,ε ∈ {0.065, 0.308, 0.653}。
- **3D 数据**:归档 benchmark(PVI、R、出口通量误差、速度 rel L2)。

## 2. 1D 定律验证(数值)

| 检验 | 结果 |
|---|---|
| 质量律 R = 1.25·PVI(参考运行) | 0.28750 = 1.25×0.23000,**1e-8 精确**(守恒账本 8e-13) |
| 通量族 ε ≤ 0.3:ΔR = 1.25·ΔPVI | 5 个 ε 全部精确到 1e-8 |
| 结构族 ε=0.065:ΔR | −0.00014 ± 0.00007 ≈ 0(R 的 0.05%) |
| 结构族 ε=0.065:场 L2 / 前端位移 | 0.098 ≈ 1.5ε / −0.36(量级参考,见 §5) |
| 混合族 θ=0.45 @ ε=0.0651(Affine 区间) | ΔR = 0.0083 vs 理论 1.25·PVI·θ·ε = 0.0084(**98.7%**) |
| 突破泄漏(ε=0.65 通量族) | 前端 v_s·u·T = 10.9 > L → 真实突破(S_out=0.45,watercut 0.72);R 短缺 0.29 vs 预测 ∫u·fw dt ≈ 0.31 体积量 ✓ |

**结论**:突破前采收率只由入口(通量)决定——零均值结构扰动移动场与前端,
但不移动采收率;通量扰动的 ΔR 由质量律精确给出。ε=0.65 处的 R 短缺是
**物理的突破效应**(泄漏通道的 1D 复现),不是数值崩溃(守恒账本 1e-13)。

## 3. 3D 精确分解(数据恒等式)

| 方法 | ε(速度 L2) | η=PVI/PVI_FEM−1 | θ=η/ε | 1.25·ΔPVI | −leak | **ΔR 实测** |
|---|---:|---:|---:|---:|---:|---:|
| Classic-DDPNM-1 | 0.6532 | 0.732 | **1.12** | +0.2112 | −0.0625 | **+0.1488** |
| NormalLinear-DDPNM-3 | 0.3075 | 0.146 | **0.48** | +0.0422 | −0.0143 | **+0.0280** |
| Affine-DDPNM-9 | 0.0651 | 0.028 | **0.43** | +0.0080 | −0.0020 | **+0.0060** |

- **通量传递精确**:PVI 比 = 1+η ≈ 1+出口通量误差(Classic 1.733≈1.727、
  W1n 1.147≈1.146、Affine 1.028≈1.027)——DDPNM 通量误差直接变成吞吐量误差;
- **质量律放大**:ΔPVI 被 1.25× 放大,通量通道占 ΔR 的 133–151%;
- **泄漏抵消 25–30%**:3D 泄漏来自多路径通道——几何固有(FEM 场本身泄漏
  3.3%,速度 std/mean ≈ 0.63 对所有方法几乎相同)+ 误差增强(Classic 0.707);
- **相干分量 θ**:W1n/Affine 的速度误差约一半是系统性通量偏差(0.43–0.48),
  Classic 的 P0 牵引空间误差几乎全相干(1.12,通量误差超过场 L2 误差)。

## 4. 结论与含义

1. **主导机制是通量,不是前端结构**:ΔR ≈ 1.25·PVI_FEM·θ·ε − leak。
   经验斜率 ΔR/ε:W1n/Affine 0.09 = 0.13(通量) − 0.04(泄漏);Classic
   0.23 = 0.32 − 0.09。交接文档"速度误差使水前端推进偏快"的表述修正为:
   **DDPNM 总通量误差经质量守恒律直接放大为采收率偏差(主导),速度结构
   误差只经快路径泄漏通道产生次级修正**。
2. **饱和度场/含水率误差仍携带结构信息**:3D 场 L2(0.075/0.142/0.395)
   与 watercut 随 ε 单调,不受上述分解影响——理论对照针对的是采收率标量。
3. **实用含义(可修复伪影)**:在 Schur 级强制 DDPNM 总通量匹配 FEM
   (通量归一化),可消除大部分采收率偏差:Classic +14.9pp 中约 +21pp、
   W1n +2.8pp 中约 +4.2pp 是通量贡献;残留为泄漏通道。这与收敛验证的
   结论(精度由牵引空间决定)互补:通量匹配是"零成本修复",模态丰富是
   "精度提升"。
4. **与收敛验证的联动**:网格收敛发现误差平台化;本分析进一步说明平台
   误差的**可操作分解**——通量部分可修,结构部分进场指标。

## 5. 局限

- 1D 前端位移指标受 P1 CG 前端 −5.7% 离散误差污染(前端位置本身 ±0.08 量级),
  只做量级参考,不作定量主张;
- ε ≥ 0.3 时 1D 单柱进入突破后区域(R 短缺是物理泄漏,但 S* 等值线前端
  测量失效);3D 泄漏与 1D 泄漏不同源(3D 是多路径几何效应,即使 FEM 场
  也泄漏 3.3%;1D 是全局突破),二者机制类比而非定量等同;
- θ(W1n/Affine 0.43–0.48、Classic 1.12)是后验拟合值,未从牵引空间理论
  先验预测——可作后续工作(逐界面通量误差的结构分析)。
