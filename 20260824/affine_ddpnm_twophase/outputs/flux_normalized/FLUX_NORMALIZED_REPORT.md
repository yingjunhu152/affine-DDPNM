# 通量归一化反事实实验(2026-08-12)

> 因果验证:1D 敏感度分解(ΔR = 1.25·ΔPVI − leak)预测 DDPNM 采收率偏差
> 由**总通量误差**主导。本实验把 DDPNM 速度场整体缩放到 FEM 入口通量
> (α = Q_FEM/Q_method),重跑同一两相输运,检验偏差是否塌缩。
> 运行:`conda run -n fenicsx --no-capture-output python run_flux_normalized_transport.py`
> (读归档 msh 原网格 + `twophase_fields.npz`,无 Stokes 求解、无网格生成)。

## 0. 结论(一句话)

**因果链钉死:通量归一化使采收率偏差从 +14.9 / +2.8 / +0.6 pp 塌缩到
+0.09 / −0.20 / −0.00 pp(|ΔR| ≤ 0.2 pp,即与 FEM 采收率不可区分)——
且比预测更强:不仅通量通道消失,泄漏通道也随吞吐量塌缩,说明泄漏本身
也主要是吞吐量(PVI 水平)的函数。**

## 1. 方法与管道验证

- 从归档 `random_sphere_partition.msh` 读回原网格(15249 胞)——保留 gmsh
  曲面几何与精确求积;**入口通量与输运历史逐位一致**(FEM 0.007279、
  Classic 0.012608、W1n 0.008344、Affine 0.007480);
- α = Q_FEM/Q_method:Classic **0.5773**(=1/1.732)、W1n **0.8724**(=1/1.146)、
  Affine **0.9732**(=1/1.028)——与 Stokes 通量误差严格一致;
- FEM 重跑 R = 0.2791,PVI = 0.2308,**与归档完全一致**(Δ= −1e-5 打印舍入);
- 输运参数与 benchmark 相同(dt=0.1, t=30, Corey 默认, SUPG, 限幅器),
  快照 snapshot_every=10(1 s 一帧)。

## 3. 解读

1. **通量通道完全消失**:PVI 归一化到 0.2308(FEM 水平),1.25·ΔPVI = 0,
   通量项归零——分解的主项被实验直接移除;
2. **泄漏通道也塌缩(强于预测)**:预测 ΔR ≈ −leak(Classic −6.25 pp),
   实测 −0.09 pp(W1n 反号 −0.20 pp)。原因:原始泄漏在 PVI 0.40
   (Classic 高吞吐)下测量;通量对齐后 PVI 回到 0.23,快路径提前出水的
   时间窗消失——**泄漏是吞吐量的函数**,与 FEM 共享同一几何泄漏(3.3%),
   差值互相抵消;
3. **残余偏差 ≤ 0.2 pp** 且符号不一致(Classic +0.09、W1n −0.20、
   Affine ≈ 0)——处于速度结构残差的噪声水平,无法与 0 区分;
4. **因果链完整**:模态空间 → 通量误差(η)→ 1.25·ΔPVI(质量律放大)→
   采收率偏差;结构误差只经次级泄漏通道进入,且该通道本身吞吐量主导。
   "通量误差是采收率偏差的主因"从预测升级为**实验证实**。

## 4. 对论文的含义

- 采收率偏差**不是方法固有限制**,而是降阶通量误差的可修复伪影:
  Schur 级通量匹配(或本实验的场级缩放)即可恢复 FEM 级采收率精度;
- 与收敛验证(模态决定精度)、均匀几何(单调跨几何)三证据闭环:
  方法的故事是"模态丰富度换精度 + 通量匹配换无偏"——两条腿都站得住;
- 保留的诚实边界:速度结构误差(场 L2、含水率曲线)不受通量归一化影响,
  仍在(如 3D 场 L2 0.075–0.395);归一化只修复标量采收率。
