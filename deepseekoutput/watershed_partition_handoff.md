## 2. 本窗口已完成的工作（公平加速比对照 + 网格收敛）

### 2.1 公平加速比对照（第三版 5.2）

**参数族**：0.10 族 = 冻结 Voronoi 0.13 族等比缩放 ×0.769（mesh 0.10 /
sphere 0.05 / boundary 0.065 / sphere_band 0.115 / boundary_band 0.10；
interface 尺寸场对 watershed 不适用）。输出 `outputs/fair_speedup/watershed/`。

结果（11,404 胞 / **50 盆** / 257 界面 / FEM 65,278 dofs / 92.9 s）：

| 指标 | V×Classic | V×Affine | W0.10×Classic | W0.10×Affine |
|---|---:|---:|---:|---:|
| 界面未知量 | 114 | 1,026 | 257 | 2,313 |
| 速度相对 L2 | 65.32% | 6.51% | 46.73% | 14.32% |
| broken-H1 | 85.85% | 17.56% | 68.44% | 34.42% |
| 压力相对 L2 | 10.30% | 2.03% | 6.51% | 3.13% |
| 出口流量误差 | 72.72% | 2.71% | 46.61% | 11.39% |
| 首次求解 | 12.2 s | 15.2 s | 15.0 s | 24.5 s |
| 相对 FEM 加速 | 9.55× | 7.66× | 6.17× | 3.78× |

- **表 7 两结论同分辨率下均成立**：Classic 画法优势（46.7% < 65.3%）；
  Affine 退化 ~2.2×（14.3% vs 6.5%）。
- **加速比同分辨率下约减半**（3.78× vs 7.66×）：残余差距来自界面数
  257 vs 114——离线库近似线性于界面数（15.0 s vs 12.2 s），是画法本身
  的离线代价，不是伪象。第三版"1.10× 塌缩是网格尺度伪象"的判断成立。

## 3. 本窗口的关键发现（必须理解）

### 3.1 修正第三版归因：watershed 上无 h 收敛，分辨率不贡献退化

第三版 2.3/3.4 把 W×Affine 的退化部分归因于"watershed 网格无界面加密、
更粗"。**证伪**：三档加密（4,311→6,586→11,404 胞）后 Affine L2 为
10.9% → 11.3% → 14.3%，不改善反略升；Classic 55.0% → 43.6% → 46.7% 也
无系统趋势。误差由画法模型误差主导（弯折界面超出仿射模态 + Classic
常数法向系数），与 5.2 的法向离散度结论一致。**不要在文档里再写
"网格更粗贡献退化"。**

### 3.2 新发现：watershed 盆数随网格非单调（77/82/50）

阈值 0.02/0.05 固定的持久性过滤对采样密度敏感：0.16 族 77 盆、0.13 族
82 盆、0.10 族 50 盆。**分区拓扑非网格不变**；Voronoi 的 27 盆由球排布
固定。影响：任何 watershed 的 h 收敛性论证都受限，须按网格重标阈值或
接受盆数变化为方法固有属性（论文期要写的 caveat）。

### 3.3 新发现：加速比低端交叉点

4,311 胞处 W 加速 < 1×（Classic 0.96× / Affine 0.80×）：FEM 参考仅
14.4 s，离线库（15.0/16.4 s，≈线性于界面数）反超。DDPNM 加速需 FEM
参考足够大以摊薄离线成本；watershed 因界面数多，交叉点比 Voronoi 高。
写加速比声明时须注明网格规模。

### 3.4 其余继承（第三版，仍有效）

浮游盆合并 `merge_floating_basins` 不可删（种子守卫不变式）；
0.13 族是冻结基准参数（不是 0.10）；Hausdorff 配对三个实现坑
（faces/used_pairs 索引错位、球对过滤不可行、点到多边形距离）勿回退；
dispersion 双口径按代码公式引用。
