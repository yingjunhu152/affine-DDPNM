## 二、核心数学结论 (已证明的)

以下结论是**条件性定理**---在每个假设成立的前提下，证明是严谨的。

| 结论 | 依赖假设 | 状态 |
|------|---------|------|
| 局部 compliance map `G_i = L_i^T H_i L_i ⪰ 0` | Ass. 1.1 (局部稳定性) | ✅ 已证 |
| `H_i^T A_i H_i = H_i`，`ker(H_i) = Range(B_i^T)` | 同上 | ✅ 已证 |
| 局部核：`ker(G_i) = span{1_{i,0n}}` | Ass. 1.1 + Ass. 2.4 (`rank(H_i^{1/2}L_i) = n_i-1`) | ✅ 条件性已证 |
| 全局 SPD：`S ≻ 0` | 上式 + Ass. 3.1 (graph anchoring) | ✅ 条件性已证 |
| 局部+全局离散质量守恒 | Ass. 1.1，ε=0 | ✅ 已证 |
| **Galerkin 最佳逼近**：`‖ξ_full − ξ_aff‖_Ŝ = min_μ ‖ξ_full − P_aff μ‖_Ŝ` | Lemma A.1 + Ass. A.1 (matching trace) | ✅ 已证 |
| 富集保证：`‖ξ_full − ξ_aff‖_Ŝ ≤ ‖ξ_full − ξ_P0‖_Ŝ` | 上式 + `Range(P_P0) ⊂ Range(P_aff)` | ✅ 已证 |

**关键限定**：
- 所有结论针对 **broken-pressure C-DD** 参考系统，**不是** monolithic 连续压力 FEM
- 仅覆盖**平面匹配接口**，不覆盖 watershed 非平面多-facet 接口
- `Ass. 2.4` (rank 条件) 是假设，**不是定理**---仅在测试几何上数值验证
